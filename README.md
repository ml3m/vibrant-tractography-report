# Vibrant Tractography Pipeline - Project Scoping & Reports

This repository contains the LaTeX source, figures, and bibliography for the MSc Visual Computing Project:
**"Dynamic Multi-Attribute Tractography in Vibrant: Analytically Ray-Traced Tapered Cones, TRX Integration, and Interactive Visual Mapping"**.

## Overleaf Setup
1. In Overleaf, click **New Project** $\to$ **Import from GitHub**.
2. Select this repository: `vibrant-scoping-report`.
3. Set main document to `main.tex` and compiler to **pdfLaTeX**.

## Local Compilation
You can compile locally using:
```bash
make
```
